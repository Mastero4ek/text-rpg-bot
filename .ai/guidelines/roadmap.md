# ROADMAP sync (always-on)

Player-facing plan: root [`ROADMAP.md`](../../ROADMAP.md). Canon detail lives in `docs/`.

## When ROADMAP changes

- **Removed** a bullet from `ROADMAP.md` → purge the same future/plan from `docs/**` (и смежных «вне скоупа / позже» списков). Не оставлять в каноне как «потом», если игрок его вычеркнул из плана.
- **Added / changed** a bullet → обновить соответствующий `docs/game|telegram|quests/*` (или явно сослаться на ROADMAP), чтобы канон и план не расходились.
- Не тащить в ROADMAP админку / Filament / техдолг.

## Skip

Чистое форматирование ROADMAP без смены смысла; правки docs, которые не про будущий скоуп игрока.
