Каталог экипа — таблица `backpack_catalog` (`ShopCatalog`); initial seed — `BackpackCatalogSeeder`. Каталог сумки — `bag_catalog` (`BagCatalog` service); initial seed — `BagCatalogSeeder` (зелья + камни). Глобалки: `settings.json` → `backpack` / `bag` / `gems` / `combat` / `repair` / `wear` / `vipRepair`. Канон таблиц/правил: корневой `docs/` (BACKPACK / BAG / EQUIPMENT / CHARACTER).
