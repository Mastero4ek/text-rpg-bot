> Баланс игры. JSON в этой папке читает `App\Services\GameConfig` (character/onboarding/settings). Каталог экипа — таблица `backpack_catalog` (`ShopCatalog`); initial seed — `BackpackCatalogSeeder`. Каталог сумки — `bag_catalog` (`BagCatalog` service); initial seed — `BagCatalogSeeder` (зелья + камни). Каталог мобов — таблица `enemy_catalog` (+ `enemy_drops`); initial seed — `EnemyCatalogSeeder`. Глобалки: `settings.json` → `backpack` / `bag` / `gems` / `combat` (`pveRewards` — база XP PvE) / `repair` / `wear` / `vipRepair`. Канон таблиц/правил: корневой `docs/` (BACKPACK / BAG / EQUIPMENT / CHARACTER / ENEMIES).
